# Research archive

This directory separates supporting historical material from active model configurations and the main research narrative.

- [Experiment history](../docs/EXPERIMENT_HISTORY.md): an English guide to the questions, comparisons, and decisions.
- [Source manifest](manifest.json): original relative paths, byte counts, and SHA256 hashes for eleven selected research notes in `sources/`.
- `config_backups/`: historical YAML backups moved from `yamls/` without changing their contents.
- [Original backtest record](../回测结果.md): retained at its original root path and used by the presentation builder.

The research notes are historical records, including provisional decisions and conversation-derived analysis. Their original wording is preserved. They are not a single unified execution release; use the current research report and result definitions when interpreting the displayed portfolio comparison.

The program ZIP remains at its original root path and is not repackaged as part of this organization.
